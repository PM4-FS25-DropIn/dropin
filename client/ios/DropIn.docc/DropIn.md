# ``DropIn``

Welcome to the official documentation for **DropIn** — the spontaneous meetup app that brings people together in real time.

## Overview

**DropIn** is a mobile app that makes spontaneous social gatherings simple. Whether you're inviting others for a last-minute coffee or joining an impromptu walk through the city, DropIn connects nearby users through real-time event discovery.

## Key Features

- **Realtime Event Map**  
  Users can view and join ongoing events through a live map interface. Events are location-based and automatically update as new ones are created or existing ones end.

- **Temporary Event Chats**  
  Each event has a built-in group chat that exists only for the duration of the event. Once the event ends, the chat and its messages are deleted automatically.

## Tech Stack

- **Frontend**: SwiftUI  
- **Backend**: Supabase
